End-to-end data pipeline from client interactions to relational persistence

  • Morgan Request Logger
  • JSON 1MB Payload Limiter
3. Security & Middleware
  • JWT Verification Guard
  • Bcrypt Password Salting
  • Regex Email Sanitization
  • Priority/Status Whitelist
  • Graceful Error Handlers
4. Database (MySQL 3306)
  • XAMPP MariaDB Engine
  • Database: task_planner2
  • Users & Tasks Tables
  • Foreign Key Cascades
  • Parameterized Queries
Client-to-Server Request Flow

Client queries initiate authenticated requests passing Authorization: Bearer <token>. Express validates headers, enforces JWT signature integrity, attaches the decoded user context to req.user, and executes sanitized parameterized queries against MySQL via mysql2/promise connection pool.

Concurrency & Process Management

The root workspace packages both frontend and backend using a single npm run dev command via concurrently. The Express server auto-initializes the database tables on startup via init-db.js with zero manual configuration required.

Relational Database Schema (MySQL)

Database: task_planner2 on localhost:3306 (XAMPP phpMyAdmin)

Database Schema
Table: `users` (Account & Verification State)
Column Type Constraint Description
id INT PK, AI Unique user identifier
username VARCHAR(100) UNIQUE, NOT NULL Unique login handle
email VARCHAR(150) UNIQUE, NOT NULL Primary email address
password_hash VARCHAR(255) NOT NULL Bcrypt salted hash
is_verified TINYINT(1) DEFAULT 0 Email verification status
verification_code VARCHAR(10) NULL One-time confirmation OTP
reset_code VARCHAR(10) NULL Password reset 6-digit OTP
reset_expires BIGINT NULL Unix timestamp expiration
Table: `tasks` (Tasks & Checklist Subtasks)
Column Type Constraint Description
id INT PK, AI Unique task identifier
user_id INT FK -> users(id) Indexed, ON DELETE CASCADE
title VARCHAR(255) NOT NULL Task title
description TEXT NULL Detailed scope notes
status VARCHAR(50) DEFAULT 'pending' pending | in_progress | done
priority VARCHAR(50) DEFAULT 'medium' low | medium | high
category VARCHAR(50) DEFAULT 'General' Engineering, Design, etc.
subtasks TEXT NULL Serialized JSON step items

Physical Storage Location: C:\xamp\mysql\data\task_planner2\ containing users.ibd and tasks.ibd. Visualized in real time at http://localhost/phpmyadmin.

RESTful API Endpoints Specification

Comprehensive routing suite covering authentication, task lifecycle, and data export

REST API
Method Route Auth Required Payload / Query Purpose
GET /api/health No None Service heartbeat verification
POST /api/auth/signup No { username, email, password } User account registration & token issuance
POST /api/auth/login No { email, password } Credential verification & JWT return
GET /api/auth/me Yes None Retrieve authenticated session profile
POST /api/auth/forgot-password No { email } Generate 6-digit password reset OTP (15 min expiry)
POST /api/auth/reset-password No { email, code, newPassword } Verify OTP and commit re-hashed password
POST /api/auth/send-verification Yes None Dispatch email confirmation OTP code
POST /api/auth/verify-email Yes { code } Set user is_verified flag to active
GET /api/tasks Yes ?status=&priority=&search= Query filtered tasks for user
POST /api/tasks Yes { title, category, subtasks... } Create task with serialized checklist
PUT /api/tasks/:id Yes { status, priority, subtasks... } Update task metadata or checklist progress
DELETE /api/tasks/:id Yes None Remove task record from database
GET /api/tasks/export Yes None Export all user tasks as JSON payload

Executive Monochrome Design System

Clean human craftsmanship eliminating the 20 AI-slop anti-patterns

Design Architecture
Aero Color Architecture
  • Canvas: Deep Obsidian (#09090b) with toggleable Studio Light (#fafafa).
  • Cards: Solid grounded #111114. No blurry glassmorphism or muddy transparencies.
  • Borders: Architectural 1px dividers (#27272a / #e4e4e7).
  • Zero Gradients: No purple, blue, or pink gradient buttons or hero texts.
Typography & 8pt Spatial Grid
  • Headlines: Inter font with tight negative tracking (letter-spacing: -0.025em).
  • Numerical Data: JetBrains Mono for metrics, time estimates, and subtask counters.
  • Strict Spacing: Consistent spatial rhythm across 8px, 16px, 24px, 32px, 48px.
  • No Emojis: Removed all emoji clutter from titles, headers, and priority pickers.
Tactile Feedback & Physics
  • Instant Response: Zero sluggish transitions. Buttons and cards respond on click with translateY(-1px).
  • Utility Icons Only: Lucide SVG icons restricted strictly to functional operations.
  • Dual Workflow Views: 3-column Kanban board and compact enterprise list table.
  • Keyboard Accessibility: Shortcuts for New Task (N), Search (/), Close (Esc).

Key Interactive Features & Workflows

Security Engineering & Test Suite

Defensive design, credential encryption, and automated testing verification

QA & Security
Defensive Security Architecture
  • Password Protection: Passwords hashed with bcryptjs using 10 cryptographic salt rounds. Hashes never leave the database.
  • Token Signing: Signed JSON Web Tokens (JWT) with 7-day expiration. Verified on protected endpoints.
  • SQL Injection Shield: 100% of database queries execute with prepared statements and parameter bindings.
  • Input Sanitization: Strict email regex validation, username length checks, and enum validation for status/priority fields.
  • Security Headers: Helmet middleware disables sensitive headers and prevents cross-site request forgery risks.

Local Deployment & Operations Guide

Quick start runbook for development and production hosting

Operations
Step 1: Database Setup (XAMPP)
  • Launch XAMPP Control Panel.
  • Click Start on MySQL and Apache.
  • Verify database is listening on port 3306.
  • Manage tables visually at http://localhost/phpmyadmin.
Step 2: Start Full-Stack App
  • Open terminal in project root:
    cd Task-planner
  • Run concurrent development server:
    npm run dev
  • Starts backend (Port 3000) and Vite frontend (Port 5173) simultaneously.
Step 3: Verification & Build
  • Access frontend at http://localhost:5173.
  • Access backend API at http://localhost:3000.
  • Run automated test suite:
    node backend/test-api.js
  • Build production package:
    npm run build
Environment Variables Configuration

PORT=3000  |  DB_HOST=localhost  |  DB_USER=root  |  DB_PASSWORD=""  |  DB_NAME=task_planner2  |  JWT_SECRET=supersecretjwtkey  |  SALT_ROUNDS=10
